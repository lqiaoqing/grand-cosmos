# 恢宏宇宙 · Grand Cosmos

从地球大气层一路拉远，穿越太阳系、奥尔特云、银河旋臂、本星系群、室女座星系团与宇宙网，抵达可观测宇宙地平线。对数缩放，光行时间标注，可交互漫游。

**在线体验（发布后）：** <https://lqiaoqing.github.io/grand-cosmos/>

手机、微信内置浏览器可直接打开。纯静态页面，不依赖外部 CDN。

## 如何打开

### 本地文件

用 Chrome 或 Edge 直接打开：

```text
D:\QWorkspace\Projects\grand-cosmos\index.html
```

或在项目目录启动本地服务：

```bash
cd D:\QWorkspace\Projects\grand-cosmos
python -m http.server 8765
```

浏览器访问 `http://127.0.0.1:8765/`。

## 哪些是真实比例

**尽量真实：**

- 太阳系轨道半径采用天文单位量级的真实距离（地球 1 AU，海王星约 30 AU 等）。
- 各层级视野距离与光行时间按物理常数换算（光速、AU、光年）。
- 邻近恒星距离取常见近似值（比邻星约 4.24 光年、天狼星约 8.6 光年等）。
- 银河系尺度、本星系群与室女座距离取数量级正确的示意值。
- 可观测宇宙共动半径约 465 亿光年；界面同时给出约 138 亿年的光行/宇宙年龄语境。

**艺术夸张（为了看得见）：**

- 行星、月球显示半径被大幅放大；真实比例下在「外太阳系」层几乎只是光点。
- 行星位置按简化开普勒相位运动，不是某日的精密星历。
- 银河旋臂、星云、宇宙网丝状结构与空洞为示意绘制，不对应巡天目录中的具体坐标。
- 仙女座等河外星系的相对方位是平面示意图，不是三维实测投影。
- 恒星与星系点集大部分为程序化生成，用于营造纵深与密度感。

## 技术说明

- Canvas2D，对数相机：`viewRadius = 10^z` 米，`z` 约从 7（地球）到 26.7（可观测宇宙）。
- 多层视差星空、柔和辉光与尘埃漂移；目标在普通笔记本上接近 60 fps。
- 无构建步骤，无打包器；可用 `file://` 或任意静态服务器托管。

## 与「太阳系尺度之旅」的关系

前作 [solar-system](https://lqiaoqing.github.io/solar-system/) 深耕太阳系内部细节（轨道根数、卫星、真实日期）。本页把镜头继续拉远，强调从家乡星球到宇宙网与地平线的**尺度震撼**与电影感漫游，两者互补。
